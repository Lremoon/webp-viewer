# WebP 横向滚动画廊看图器 — 需求文档

> 状态：需求已定稿 ｜ 更新：2026-06-30 ｜ 阶段：原型 v0.3

## 1. 目标

Windows 桌面看图工具，浏览 WebP（含动图）/ JPG / PNG。核心体验是**横向缓缓自动滚动画廊**：图片横向并排铺成一条长卷，匀速滚动，循环不息。支持暂停、滚轮调速、反向滚动。

## 2. 核心交互

| 项 | 规格 |
|---|---|
| 启动 | 选择某张图片打开，以它为中心双向缓存 |
| 滚动 | 匀速横向滚动，50 px/s 起步（可正可负） |
| 循环 | 滚到末尾无缝回到第一张（双向均循环） |
| 暂停/继续 | 工具栏「⏸ 暂停」按钮，或**点击图片区域**（快捷键） |
| 滚轮控速 | 向上 = +10 px/s（加速正方向），向下 = −10（可过 0 变负即反向） |
| 速度输入框 | 同步显示当前 speed（含负数），可直接输入 |

## 3. 加载 / 卸载（双向缓存）

- `maxCached` 奇数内部 +1 偶数化（**UI 仍显示用户设定的原值**），`half = 偶数化后 ÷ 2`
- 缓存窗口 = **可见图 前 half 张 + 后 half 张**
- 以**选中文件为中心**初始缓存（不再固定从第一张）
- 正向滚 → 尾部加载、头部卸；反向滚 → 头部加载、尾部卸
- 内存平稳，不随图片总数增长

## 4. 尺寸模式（两档）

核心原则：横向滚动 → 宽度方向无限，**只约束高度不裁剪**。等比缩放，不变形。

1. **适应高度**（默认）：每张图等比缩放到高度 = 视口高度，宽度按各自比例。
2. **原始 1:1**：原始像素，超大图高度超屏时可纵向拖动看。

## 5. 格式支持

- WebP（含动图）、JPG、JPEG、PNG
- 尺寸预读统一用 `imagesize` crate

## 6. 约束

- 平台：仅 Windows 10+
- 速度：像素/秒，默认 50，可负；滚轮步进 10
- 缓存张数：可配置，默认 10（奇数内部 +1）
- 排序：文件名自然排序（`img2` < `img10`）

## 7. 技术栈

- Tauri v2（WebView2 + Rust）、前端 Vite + TypeScript
- animated webp 靠浏览器内核 `<img>` 原生渲染
- 滚动引擎：绝对逻辑坐标 + 取模循环，支持双向
