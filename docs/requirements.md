# WebP 横向滚动画廊看图器 — 需求文档

> 状态：需求已定稿 ｜ 更新：2026-06-29 ｜ 阶段：原型

## 1. 目标

Windows 桌面看图工具，专浏览 WebP（含动图）。核心体验是**横向缓缓自动滚动画廊**：图片横向并排铺成一条长卷，匀速从右向左流过，循环不息。

先做原型，手动控制（暂停 / 跳转 / 拖拽）以后再加。

## 2. 核心交互

| 项 | 规格 |
|---|---|
| 启动 | 选择某张 webp 打开 |
| 目录缓存 | 打开时读取同目录所有 webp 路径并缓存（自然排序） |
| 预加载 | 显示首张 + 预载其后 4 张 |
| 滚动 | 整体匀速从右向左，50 px/s（可调） |
| 循环 | 滚到目录末尾无缝回到第一张 |
| 手动控制 | 原型阶段无（后续再加） |

## 3. 加载 / 卸载策略

- 滚动中尾部持续动态加载后续图
- 移出屏幕的图**延迟卸载**
- 缓存窗口上限可配置，默认 10 张；满了才卸载最早（已移出屏幕）的那张
- 目标：内存 / 显存平稳，不随图片总数增长

## 4. 尺寸模式（两档，可切换）

核心原则：横向滚动 → 宽度方向无限，**只约束高度不裁剪**。等比缩放，不变形。

1. **适应高度**（默认）：每张图等比缩放到高度 = 视口高度，宽度按各自比例自由延伸。横图宽、竖图窄，横向流过都不裁。
2. **原始 1:1**：原始像素，超大图高度超屏时可纵向拖动看（此档为主动选原尺寸，超屏属预期）。

> 不设"完整显示 contain"：横向滚动下它会缩到留白，与长卷直觉冲突。

## 5. 格式支持

- WebP（含动图）、JPG、JPEG、PNG
- 尺寸预读统一用 `imagesize` crate（替代手写 webp 头解析）

## 6. 约束

- 平台：仅 Windows 10+
- 速度：像素/秒，默认 50，UI 可调
- 缓存张数：可配置，默认 10
- 排序：文件名自然排序（数字按数值：`img2` < `img10`）

## 7. 技术栈

- **Tauri v2**（WebView2 渲染 + Rust 后端）
- 前端：Vite + TypeScript（vanilla，无框架）
- 决定因素：animated webp 靠浏览器内核 `<img>` 原生渲染
- 环境就绪（2026-06-29）：Node v24 ✅ / npm 11 ✅ / Rust 1.96 ✅ / MSVC Build Tools 2022+2026 ✅
